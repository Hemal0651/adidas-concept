# Adidas Elevate — Interactive Web Experience

An interactive 3D footwear showcase web application built for **Adidas Elevate**.

## 🚀 Features
- **Dynamic Colorway Themes**: Elevate Phantom, Elevate Dune, Elevate Slate, Elevate Frost.
- **3D Parallax & Depth Effects**: Interactive shoe pop-out colorway cards with depth shadows.
- **Ultra-Responsive Mobile UX**: Mobile drawer navigation, responsive typography, and glassmorphic UI elements.
- **Interactive Modals & Drawer**: VIP pair reservation modal, interactive shopping cart drawer.

## 🛠️ Technology Stack
- HTML5, CSS3 (Vanilla Design System)
- Vanilla JavaScript (Interactive State & Theme Engine)
- FontAwesome Icons

## 💻 Local Development
Simply serve the files using any static HTTP server or open `index.html` in your browser.
